# Minecraft 26.3 port validation

Validated locally on 2026-09-21 for MultiGolem `0.8.2+mc26.3`.

## Changes

- Ported Enderman targeting to `Enderman` and loot context access to `getOptional`.
- Shared the new holder-backed integer loot count provider between Fabric and NeoForge, preserving each variant's inclusive drop bounds.
- Updated to Gradle 9.6.0, Loom 1.17.21, Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, Mod Menu 21.0.0-beta.1, NeoForge 26.3.0.8-beta, and ModDevGradle 2.0.147. Java 25 remains required.
- Restricted both loader manifests to Minecraft 26.3; future Minecraft releases require separate validation.

## Verified

- `gradlew.bat build check` passed using Temurin Java 25.0.3.
- All 373 JUnit tests passed, with no failures, errors, or skipped tests. The loot regression test samples every variant's configured drop range and confirms both endpoints remain reachable.
- Both main and client source sets compiled for Fabric and NeoForge.
- Separate development servers in disposable, loopback-only worlds reached `Done` on both loaders. Console block placement created a diamond golem with the diamond identity, 350 health, and the configured attribute modifiers.
- Killing that golem produced 4 diamonds on Fabric and 3 diamonds on NeoForge, within the configured range. Vanilla drops were also present.
- Both servers completed data reload, explicit world save, and clean shutdown with exit code 0.
- The two client renderer mixin descriptors match the downloaded 26.3 `IronGolemRenderer` methods.
- Both packaged jars contain the client renderer class and the intended version constraints. Their displayed mod version is `0.8.2`, following the existing artifact/display-version convention.

## Limits

Runtime smoke tests used development runs rather than installing the packaged jars into a separate launcher. Visual client behavior, Mod Menu interaction, multiplayer connections, saved-golem reload across restarts, and the complete gameplay checklist were not tested. Startup logged Windows performance-counter diagnostics and a default flat-world generator-settings warning; NeoForge also reported its existing `logoFile` deprecation. These did not prevent startup or the recorded gameplay checks.

Local logs and the disposable smoke harness are under the ignored `build/compatibility-26.3/` directory. The earlier compatibility assessment there describes the original 26.2 build, before this port.

## Artifacts
